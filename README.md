# Python Fundamentals Challenges

Four small practice exercises demonstrating Python basics: capitalizing words, Fizz/Buzz-style divisibility, collecting unique values from nested lists, and counting case-insensitive word frequencies.

## Run
No third-party Python packages required. Open `python_fundamentals_challenges.ipynb` in Jupyter or Google Colab and run every cell. Each example includes simple `assert` checks.

## What was fixed
- Empty-string capitalization now returns an empty string.
- Divisibility function returns strings for regular numbers and explains zero-divisor errors.
- Word frequency handles commas, punctuation, tabs and repeated spaces more consistently.
- The exercises retain readable loops and dictionaries rather than converting everything to one-liners.
